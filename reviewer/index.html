GOOGLE PLAY REVIEWER SETUP

A complete local lyrics test.

One small test library provides original audio and timed lyrics for a 24-second review of LiveSetPro Remote.

Before you begin

Use the Microsoft reviewer account supplied privately in Google Play App Access to install or open LiveSetPro for Windows, version 1.2.4 or newer, with full access. LiveSetPro Remote on Android requires no Android account.

You need a Windows PC and an Android phone with LiveSetPro Remote 1.0.1 or newer. Download the test library below to the PC.

1. Import the test song

  1. In LiveSetPro, open Settings → Import library under Import and export. These instructions use the English interface.
  2. Select the downloaded LiveSetPro-Reviewer-Test.livesetpro file. Keep it as one file; do not unzip it.
  3. Review the preview, then choose Import library → Confirm and add. In an empty library, this adds one song, one audio file and one lyric document.
  4. After import completes, close Settings and open All Songs. Double-click LiveSetPro Reviewer Test, then pause it while setting up the phone.

2. Connect the phone

  1. Click Lyrics in the Windows player. The included test lyrics appear in this window.
  2. Open Remote → Start Remote. Wait for the fresh pairing QR code.
  3. On Android, open LiveSetPro Remote → Scan QR and scan the code shown on the PC. Approve the normal camera and wireless-connection permission prompts.
  4. After the phone connects, return to the Windows player, seek to 0:00 and start playback.

3. Watch the lyric sections change

Audio plays on the PC. The phone shows the test lyrics, playback position and active stanza. The four sections change during the 24-second test:

0–6 secondsFirst section6–12 secondsSecond section12–18 secondsThird section18–24 secondsFinal section

Use the PC to pause, seek or replay. To finish, tap Disconnect on Android and stop Remote on the PC.

Existing-network fallback

If Direct is unavailable, connect both devices to the same private local network. In the Windows Lyrics window, open Remote → Manual connection → Start on existing network, then scan its fresh QR. Avoid guest networks that prevent devices communicating with one another.

About this test resource

The audio consists of original generated test pulses. The lyrics were written solely for app review; no commercial recording, existing song or private user content is included. This test content may be copied and redistributed for review and testing.

Internet access is needed for the initial installation and download. LiveSetPro Direct does not require Internet afterward. Pairing QR codes are intentionally session-specific. Generate a fresh code in your own session; this page provides no account credentials or permanent pairing code.
