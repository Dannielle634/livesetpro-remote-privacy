GOOGLE PLAY REVIEWER SETUP

LiveSetPro Remote — reviewer guide

Updated: October 24, 2026. Prepared for the next Remote release; not evidence that these controls are in the currently distributed Android 1.0.1 / code 2 or Windows 1.2.4.0.

Compatible apps and access

Use a Windows LiveSetPro host and Android Remote build that both support negotiated Player controls and Karaoke Follow control. Confirm the supplied release/build supports these features; secure QR support alone does not establish control compatibility.

Install/open LiveSetPro for Windows with full access using the Microsoft reviewer account supplied privately in Google Play App Access. LiveSetPro Remote has no Android app account. Public Windows download: https://apps.microsoft.com/detail/9N369WGHGVTS. Keep reviewer credentials out of this guide and public downloads.

1. Import review content

  1. On a reviewer PC/profile, open Settings → Import library under Import and export. These steps use the English interface.
  2. Select the downloaded .livesetpro archive as one file; do not unzip it.
  3. Review the import preview, then choose Import library → Confirm and add.
  4. The existing archive adds one song, one audio file and one lyric document to an empty library. Open All Songs and double-click LiveSetPro Reviewer Test, then pause while pairing.
  5. Once the separate three-song archive is validated, use its documented playlist/order for multi-song tests. Do not re-import content already present just to repeat a test.

2. Pair and verify Read-only

  1. Open Lyrics → Remote in Windows and start a new Remote session. Wait for the fresh session QR.
  2. On Android choose Scan QR, scan it, and approve the necessary camera/Wi-Fi prompts.
  3. Confirm the connected session is Read-only / control disabled. Android control requests must be disabled. Lyrics and playback information can still be received.
  4. For the existing 24-second song, start playback on Windows from 0:00. Confirm the phone follows the four lyric sections at 0–6, 6–12, 12–18 and 18–24 seconds. Audio remains on Windows.

3. Authorize and test Player

  1. In the Windows Remote panel, explicitly select Allow control. Open Player on Android and wait for the host's current state.
  2. Verify Play/Pause and Stop against Windows. Windows is authoritative; a sent request is not proof of success until the returned state reflects it. Android does not stream audio or offer remote seeking through its progress indicator.
  3. With the validated A, B, C playlist active, verify Next changes A → B and Previous returns B → A. Test Previous within the first three seconds of B; later presses can restart the current song as on Windows.
  4. Verify Repeat Off, All and One update the Windows setting and the Android state. For end-of-track checks with the neutral playback settings above: Off stops automatic advancement, One repeats the current song, and All traverses A → B → C → A. Multi-song acceptance remains pending until the three-song asset exists.
  5. Adjust Android's Windows volume control and verify the LiveSetPro player volume changes on the PC. This is normalized app volume, not phone volume or Windows system master volume. Check the returned volume/mute state. Shuffle is displayed where supported; this guide does not promise an Android Shuffle command.

4. Test Lyrics and Karaoke Follow

  1. Open Lyrics on Android. Use Settings (Aa) to change font size and left/center/right alignment. Confirm only the phone presentation changes; Windows formatting remains independent. Return to Lyrics and switch tabs to confirm presentation/session continuity.
  2. With timed review lyrics and playback running, use Android Karaoke / Follow to turn follow Off and On. Confirm Windows Karaoke Follow and the returned Android state change together; On follows the timed active stanza.
  3. Change Karaoke Follow locally on Windows and confirm Android updates. Manual scrolling is separate from the authoritative follow setting.

5. Revoke control and reset authorization

  1. Revoke Allow control in the Windows Remote panel. Confirm Android returns to Read-only / control disabled and Player/Karaoke control requests are disabled. Local font/alignment settings remain usable.
  2. Stop Remote on Windows, then start a new session and scan its fresh QR with Android.
  3. Confirm the new session starts Read-only even if control was allowed in the previous session. Pairing does not grant permanent control.
  4. Finish by disconnecting Android and stopping Remote on Windows. Disconnect does not delete the Windows library or reset locally saved Repeat, volume or Karaoke Follow preferences.

Existing-network option and compatibility

If Direct is unavailable, connect both devices to the same trusted local network. In Windows Lyrics → Remote, choose Manual connection → Start on existing network and scan its new QR. Avoid guest/client-isolated networks. Internet is needed for initial installation/download, not the subsequent Direct session.

An older host may provide read-only lyrics/playback fallback only if its QR, authentication, TLS/WSS and base message protocol remain compatible. Missing control capabilities can disable controls without preventing compatible read-only use. Hosts with incompatible QR/TLS transport must be updated; no plaintext or obsolete-QR fallback is promised. Windows 1.2.4.0 and Android 1.0.1/code 2 remain the baseline for the earlier one-song secure lyrics workflow, not proof of the new control feature set.

Privacy and support

Remote data travels directly between the paired devices over authenticated TLS/WSS; no LiveSetPro developer cloud relay receives it. Audio stays on Windows. Pairing QR codes and credentials are session-specific; generate your own current QR. Never publish reviewer passwords, tokens, Wi-Fi credentials or private library content.
